# Native agent loop: state of the art and where Fabric stands
Status line: pinned to commit bc5a6d3; sources accessed 2026-11-07.

## What this component does in Fabric
- `internal/agent/loop.go` runs a direct Anthropic Messages loop inside the `fab` process: model call, tool calls, tool results, repeat. Messages are stored as exact JSON bytes (`bytea`, not `jsonb`) in `agent_messages`; tool calls in `agent_tool_calls` with a one-way state machine; run state in `agent_runs` (`internal/store/migrations/0022_agent_turns.sql`). `agent_messages` rejects UPDATE and DELETE by trigger (`0022:59-64`).
- Before each request the loop places a durable worst-case spend hold and settles it to the actual cost after the response (`loop.go:334-353`, `internal/agent/prices.go:78-93`). Caps come from the grant for run, job and month (`internal/native/native.go:222-228`).
- A restart reloads the stored turns and continues (`loop.go:150-246`). A side-effecting tool left `EXECUTING` by a dead process becomes `INTERRUPTED` with a synthetic result and is never re-run; a read-only one is repeated (`loop.go:414-466`). The config hash pins model, system prompt, tools, shell allowlist, oracle hooks, caps, turn and wall limits, and prices; a changed hash refuses the resume (`loop.go:100-125`, `native.go:326-333`, `ErrConfigChanged` at `db.go:27`).
- Tools are `read`, `grep` and an allow-listed `shell`, each run through the host sandbox (`native.go:219-223`); every call first goes to an external policy oracle that denies on any error (`internal/policy/oracle.go:20-71`). Output is redacted at creation and capped at 64 KiB (`loop.go:83-85,491-495`).

## State of the art
- Anthropic's definition: agents are LLMs using tools in a loop on environmental feedback; use the simplest solution, include stopping conditions such as a maximum number of iterations, and test in sandboxes with guardrails. [Building effective agents](https://www.anthropic.com/engineering/building-effective-agents) (accessed 2026-11-07), H.
- Claude Agent SDK: terminal subtypes `success`, `error_max_turns`, `error_max_budget_usd`, `error_during_execution`, `error_max_structured_output_retries`; `max_budget_usd` is checked after each model response, so spend can overshoot by one response and the docs say to leave headroom; read-only tools may run in parallel and state-changing tools run in sequence; hooks can block a call; a denied call returns a rejection as the tool result. [Agent loop](https://code.claude.com/docs/en/agent-sdk/agent-loop) (accessed 2026-11-07), H.
- OpenAI Agents SDK: `max_turns` with `MaxTurnsExceeded`; error handlers for max turns, refusals and invalid output that do not replay tool side effects; `RunState` resumes paused runs; durable-execution integrations (Temporal, Restate, DBOS, Dapr) cover restarts. [Running agents](https://openai.github.io/openai-agents-python/running_agents/) (accessed 2026-11-07), H.
- Context management: compaction near the limit, notes outside the window, sub-agents returning summaries, just-in-time retrieval. [Context engineering](https://www.anthropic.com/engineering/effective-context-engineering-for-ai-agents) (accessed 2026-11-07), H. API-level primitives: context editing (`clear_tool_uses_20250919`, default trigger 100k input tokens, `clear_at_least`, beta header `context-management-2025-06-27`) [docs](https://platform.claude.com/docs/en/build-with-claude/context-editing) (accessed 2026-11-07), H; server-side compaction [docs](https://platform.claude.com/docs/en/build-with-claude/compaction) (accessed 2026-11-07), M (overview page only). Header names and defaults change; re-check before relying on them.
- OpenHands condensers summarize the middle of a long history and record a `Condensation` event listing forgotten event ids, so the view stays reproducible from the log. [OpenHands condenser](https://docs.openhands.dev/sdk/arch/condenser) (accessed 2026-11-07), H.
- Prompt caching: prefix order tools, system, messages; up to four explicit breakpoints or automatic caching; TTL 5 minutes or 1 hour; reads cost 0.1x (0.05x on some current models); any tool-definition change invalidates the cache; `tool_use` input key order must be stable, and the page names Go as a language that can randomize it. [Prompt caching](https://platform.claude.com/docs/en/build-with-claude/prompt-caching) (accessed 2026-11-07), H (first 100k of 164k characters).
- Long-running work: progress file, git history and a feature list that the agent may only flip when verified; failure modes include declaring victory early. [Effective harnesses](https://www.anthropic.com/engineering/effective-harnesses-for-long-running-agents) (accessed 2026-11-07), H. Resume from the point of error rather than restart, with deterministic retries and checkpoints. [Multi-agent research system](https://www.anthropic.com/engineering/multi-agent-research-system) (accessed 2026-11-07), H.
- Tool design: few high-signal tools, truncation with steering hints, actionable errors. [Writing tools for agents](https://www.anthropic.com/engineering/writing-tools-for-agents) (accessed 2026-11-07), H.
- Stuck detection: OpenHands detects repeated action-observation pairs, repeated errors, monologues and ping-pong patterns, on by default; a reported false positive on an intentional polling agent suggests per-task thresholds. [Stuck detector](https://docs.openhands.dev/sdk/guides/agent-stuck-detector) (accessed 2026-11-07), H; [issue 762](https://github.com/OpenHands/software-agent-sdk/issues/762) (accessed 2026-11-07), L (snippet).

## Comparison
| Practice | Fabric today (file:line and test) | Verdict | Why |
|---|---|---|---|
| Budget enforcement | Durable hold taken before the request is sent; request refused when the cap cannot cover the worst case; unknown-cost streams stay charged at the hold (`loop.go:334-353,291-311`); `TestBudgetHeldBeforeSend` (`internal/agent/budget_test.go:20`), `TestBudgetExhaustedSendsNothing` (`:44`), `TestBudgetCumulative` (`:57`), `TestTransportAfterWriteCharged` (`crash_test.go:188`), `TestMonthCeilingStopsLoop` (`internal/native/month_test.go:54`) | ahead | The Agent SDK documents a post-response check with overshoot of one response. Fabric's hold is pre-call and survives a crash (`TestHoldSurvivesCrash`, `budget_test.go:130`). Cost: the hold counts every body byte as a token, so it can refuse a request that would have fit. |
| Crash resume without repeating effects | Stored turns reloaded; side-effecting `EXECUTING` call becomes `INTERRUPTED`, never re-run (`loop.go:414-466`); `TestCrashResume` covers 10 crash points (`crash_test.go:42`) | parity | OpenAI documents that error handlers do not replay side effects and offers Temporal-style durability; Fabric does it in the database with at-most-once for side-effecting tools. There is no per-call idempotency key to retry safely, only the stored `tool_use_id` row state. |
| Partial streams | A truncated stream never executes its `tool_use`; `TestPartialStreamNeverExecutes` (`crash_test.go:127`), `TestToolUseWithoutToolStopNotExecuted` (`loop_test.go:105`) | parity (peer not documented) | Cited peers do not describe this case. |
| Resume against changed configuration | Config hash refuses; `TestConfigChangeRefused` (`crash_test.go:246`) | parity (peer not documented) | Peers do not document pinning. Fabric needs it because signed thinking blocks are bound to the prefix (`loop.go:94-99`). |
| Single runner per attempt, stale writer | Advisory lock and fence on every write; `TestSecondRunnerRefused` (`crash_test.go:205`), `TestStaleFenceRefused` (`loop_test.go:156`), restart cap default 5 (`native.go:314-319`), `TestCrashLoopBreaker` (`crash_test.go:147`) | parity | Same goal as durable-execution engines on a smaller scale. |
| Terminal reasons | `done`, `parked` (with note for refusal, max_tokens, context exceeded, pause_turn, unknown stop reason), `budget_exhausted`, `max_turns`, `wall_exhausted` (`types.go:151-155`, `loop.go:248-263`); `TestUnknownStopReasonParks`, `TestMaxTokensRefusalPark` | parity | Comparable to the SDK subtypes; refusal and context errors share `parked`, distinguished only by a note. |
| Tool policy before execution | Oracle fails closed, denial returned as tool result; `TestOracleFailsClosed` (`policy_test.go:118`), `TestGuardRefusalDoesNotRun` (`loop_test.go:119`), `TestInjectionCannotApprove` (`policy_test.go:152`) | parity | Same shape as SDK PreToolUse hooks. |
| Tool concurrency | Sequential (`loop.go:414-466`) | behind | The SDK runs read-only tools in parallel. |
| Context compaction or editing | Not found. Context overflow parks the run (`loop.go:256`, `"context window exceeded"`) | behind | Peers offer compaction, context editing or condensers. Growth is bounded by the grant's turn, wall, token and money caps (`loop.go:204-232`), not by trimming. |
| Prompt caching | Not found: no `cache_control` is set by the loop (only a grant-supplied `Extra` map reaches the request, `native.go:235`). Cache token counts are recorded and priced (`types.go:17-18`, `prices.go:70-72`) | behind | Long loops re-send the full prefix at full price. Raw-byte storage and `json.RawMessage` tool definitions keep the prefix bytes stable (`TestBuildRequestVerbatimAssistantContent`, `client_test.go:326`, `TestAssistantHistoryIsImmutable`, `loop_test.go:71`), which a cache needs. |
| Stuck-loop detection | Not found. Only turn, wall, token and money caps | behind | OpenHands has a detector; here a repeating loop runs until a cap. |
| Verifier before success | Not found: an `end_turn` stop is `done` (`loop.go:250`) | behind | The long-running-harness post lists early victory as a failure mode. |
| Tool-result size handling | Truncated at 64 KiB with a fixed marker (`loop.go:493-495`); read/grep/shell have separate output caps (`native.go:216-221`) | parity | No steering hint to narrow the query. |

## Not verified
- The native path takes `max_turns` from its grant (`native.go:236`); I did not find a default for it.
- Live behavior of the loop against the real Anthropic API; tests use a recorded fake server (`fakeapi`).
- That a grant never supplies a `cache_control` entry through `Extra`; only the loop's own code was checked.
- Confined tool execution on a real host: `TestNativeToolsConfined` is skipped (`internal/tools/tools_test.go:259`).
- Beta header names and thresholds in the sources above are as printed on 2026-11-07.
